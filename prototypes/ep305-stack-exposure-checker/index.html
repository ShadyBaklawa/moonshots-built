▣ Stack Exposure Checker

For web agencies and freelancers who keep WordPress/PHP sites alive — paste what a client is running, see exactly what's exposed.

Decade-old PHP flaws are being rediscovered fast — AI-assisted researchers recently turned up critical, password-free takeover bugs in code that's been running for years. This checks one stack against two live, public databases: endoflife.date for PHP support status and OSV.dev for known vulnerabilities in your Composer packages.

From php -v, your host's control panel, or phpinfo().

Nothing is uploaded anywhere except the two public lookup services below — your own browser talks to them directly.

How this works

    
    
      
  • PHP support status — live lookup against endoflife.date. If that lookup fails, a bundled snapshot (dated ) is used and clearly marked.
    • 
      
  • Package vulnerabilities — live query against OSV.dev for each package in the Packagist ecosystem. This always needs a live connection; there is no offline substitute for your own packages.
    • 
      
  • Example mode — instantly renders a real, previously-captured result set for a known outdated stack, so you see output in well under a second with no live request. A "Refresh with live data" button re-runs the same stack against OSV.dev right now, if you want to confirm it's still current.
